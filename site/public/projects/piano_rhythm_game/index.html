Java Swing 피아노 리듬게임

키보드로 피아노를 연주하고, 내려오는 타일에 맞춰 리듬게임을 즐길 수 있는 Java Swing 기반 프로그램입니다.

  • 제작 기간: 2023년 10월 ~ 12월
  • 진행 형태: 팀 프로젝트
  • 사용 기술: Java · Swing
  • 담당 역할: 아이디어 구상, 피아노 건반과 키보드 매핑 구현
  • 소스 코드: GitHub

프로젝트 소개

음악을 연주하는 경험과 리듬게임을 하나의 프로그램에 담고자 했습니다. 피아노 건반에 대응하는 키보드 키를 누르면 피아노 소리가 나오며, 자유롭게 연주하거나 화면 위에서 내려오는 타일에 맞춰 플레이할 수 있습니다.

주요 기능

피아노 시뮬레이션 모드

키보드 입력을 피아노 건반과 연결해 자유롭게 연주할 수 있습니다. 별도의 악기 없이 컴퓨터 키보드로 피아노 소리를 내는 기능입니다.

리듬게임 모드

화면 위에서 내려오는 타일을 보고, 해당 건반에 대응하는 키를 타이밍에 맞춰 누르며 플레이합니다.

담당한 부분

팀원들과 프로젝트 아이디어를 구상하고, 피아노 건반과 키보드 입력을 연결하는 기능을 구현했습니다. 각 키에 대응하는 건반과 소리를 매핑해 키보드로 피아노를 연주할 수 있도록 만들었습니다.

돌아보며

화면 구성과 전반적인 완성도에는 아쉬움이 남는 프로젝트입니다. 개발 당시에도 Swing이 실제 현업에서 얼마나 활용되는 기술인지, 학습과 구현에 들이는 시간이 앞으로 어떤 도움이 될지 고민했습니다.

지금 다시 진행한다면 구현할 기능뿐 아니라, 사용할 기술이 프로젝트의 목적에 적합한지와 완성 후 어떻게 활용할 것인지도 함께 고려하고 싶습니다.

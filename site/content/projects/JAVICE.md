전북대학교 웹개발 동아리 JAVICE를 소개하기 위한 홈페이지 제작에 참여했습니다.

- **제작 기간:** 2023년 11월 ~ 12월
- **사용 기술:** React · TypeScript · Tailwind CSS
- **담당 역할:** 템플릿 기반 UI 조정 및 소개 콘텐츠 작성
- **홈페이지:** [JAVICE 홈페이지](https://javice-jbnu.github.io/homepage/)
- **소스 코드:** [GitHub](https://github.com/javice-jbnu/homepage)

## 프로젝트 소개

동아리를 외부에 소개할 수 있는 웹페이지를 만들고자 진행한 프로젝트입니다.
기존 템플릿을 바탕으로 화면을 조정하고,
동아리 소개에 필요한 내용을 채워 홈페이지의 기본 틀을 구성했습니다.

## 담당한 부분

템플릿의 UI를 동아리 홈페이지에 맞게 조정하고,
기존 예시 콘텐츠를 동아리 관련 내용으로 교체했습니다.
화면 구성과 소개 콘텐츠를 정리하는 작업을 맡았습니다.

## 돌아보며

홈페이지의 기본 틀을 구성했지만,
내용과 기능을 충분히 보완해 완성도를 높이는 단계까지 이어가지 못한 점이 아쉽습니다.

동아리의 활동을 꾸준히 기록하고 소개하는 공간으로 발전시키고 싶었으나,
당시에는 기본적인 구성에 머물렀습니다.
기회가 된다면 부족했던 부분을 보완해 실제로 활용되는 홈페이지로 완성하고 싶습니다.

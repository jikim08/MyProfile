LPPLS 모델의 C++ 전환 및 유전알고리즘 최적화

연세대학교 핀테크센터의 MATLAB 기반 LPPLS 모델을 C++로 전환하는 2인 팀 프로젝트에 참여했습니다. 유전알고리즘 코드의 전환과 최적화를 담당했습니다.

  • 제작 기간: 2023년 6월 ~ 8월
  • 진행 형태: 2인 팀 프로젝트 · 외주 개발
  • 사용 기술: MATLAB · C++ · 유전알고리즘
  • 담당 역할: 유전알고리즘의 MATLAB → C++ 전환 및 알고리즘 최적화
  • 주요 결과: MATLAB 코드와 C++ 코드의 결과 일관성 확인

프로젝트 소개

기존 MATLAB 기반 LPPLS 모델을 C++ 환경으로 옮기는 프로젝트입니다. 기존 알고리즘의 동작을 이해하고 C++로 전환한 뒤, 두 환경에서 도출되는 결과가 일관되는지 확인하는 작업을 진행했습니다.

담당한 부분

기존 MATLAB 코드에서 유전알고리즘이 수행하는 과정을 분석하고, 이를 C++ 코드로 옮겼습니다. 전환 이후에는 결과를 비교하며 구현을 점검하고, 최적화 과정에서 발생하는 문제를 개선했습니다.

어려웠던 점과 해결 과정

최적화 과정에서 지역 최솟값(local minimum)에 반복적으로 빠지는 문제가 있었습니다. 더 나은 해를 탐색하지 못하고 특정 결과 부근에 머무르는 원인을 찾기 위해 약 2주 동안 알고리즘과 코드를 점검했습니다.

변이 개수를 여러 차례 조정하고, 코드 전환 과정에서 빠뜨리거나 잘못 구현한 부분이 없는지 확인하면서 탐색이 정체되는 문제를 개선해 나갔습니다.

최종적으로 MATLAB 코드와 C++ 코드의 결과 일관성을 확인했습니다.

돌아보며

처음 접하는 LPPLS 모델을 이해하고, 유전알고리즘을 다시 공부해 실제 코드에 적용해볼 수 있었던 프로젝트입니다. 단순히 문법을 바꾸는 것만으로는 충분하지 않았고, 알고리즘의 동작과 결과를 이해해야 전환한 코드를 점검할 수 있었습니다.

처음 맡은 외주 개발이라 긴장과 책임감도 크게 느꼈습니다. 특히 최적화가 정체되는 문제를 오랫동안 살펴보면서, 설정을 조정하고 결과를 비교하며 원인을 좁혀가는 과정을 경험했습니다.
